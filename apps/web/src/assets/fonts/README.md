- Upstream: <https://github.com/google/material-design-icons>
- Downloaded asset (Google Fonts, version 382): <https://fonts.gstatic.com/s/materialsymbolsoutlined/v382/kJEPBvYX7BgnkSrUwT8OhrdQw4oELdPIeeII9v6oDMzBwG-RpA6RzaxHMPdY40KH8nGzv3fzfVJO1Q.woff2>
- The font binary is unmodified. Vite bundles it under `/assets/` for local serving; the application does not contact Google Fonts or a CDN at runtime.

Body and code typography use the configured system fallback stacks; no other font downloads are required.
