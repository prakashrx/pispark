# Tidying .mind

The folder is only useful while it is true and short. Tidy quietly, and involve the person only when something needs them.

1. **Notes against reality.** Read `.mind/notes.md` and each page under `.mind/notes/`. Where something can be checked cheaply (a path, a service, a setting, a command), check it. Rewrite what is no longer true and remove what no longer matters. Never drop something the person told you: if it looks wrong now, put a question under "Waiting on you".
2. **One place for each thing.** Merge duplicates. Move detail that has grown in `notes.md` into a page, and leave one line pointing to it. Remove anything that only repeats what the place's own documents or code say, and link to them instead.
3. **Tasks that haven't moved.** For each entry under "Doing" and "To do", ask whether it is still wanted.
   - If you can safely do the next step, do it.
   - If it has been overtaken, remove it and say so in a "Done lately" line.
   - If only the person can say, ask under "Waiting on you".
   - A question that has waited more than a week goes in your report, once.
4. **Skills.** For each skill in `.mind/skills/`, check that its steps still match the place. Fix it or remove it (the `mind-skills` skill says how).
5. **Layout problems** listed at the start of the run: fix them.

Then report in at most three lines, and only what needs the person. If nothing does, say "Tidied; nothing needs you."
